# 调研 C：中文社区 AI 短剧制作工作流（2026-10-17）

## 八阶段流水线（社区高度收敛）
写剧本→锁角色→出分镜→关键帧→图生视频→声音→剪辑→资产复用。
人工介入点：剧本结构（3秒钩子+30秒反转）、选脸抽卡、分镜逐镜确认、关键帧一致性人审（错图不进视频环节——动态放大问题）、抽卡筛选、台词与镜头时长对齐、剪辑节奏筛选（5s 素材留 1-3s）。

## 痛点（按频率）
1. 角色一致性/跳脸（最高频）：解=参考图+@引用+人物一致句角色卡
2. 抽卡浪费：80% 时间在抽卡；返工率 50%（agent 辅助→10% 内）；~60 元/分钟算力；定妆静帧 7-14 元/张
3. 流程割裂：文档+即梦+剪映多 App 切换，整理时间最被低估
4. 命名混乱："段01_v3_final(2).mp4" 地狱
5. 音画对齐：声音留最后是常见错误（应在分镜阶段估台词时长）
6. 分镜门槛：普通人不会景别/运镜 → LLM 模板补课
7. 成本不可预算：新手只看生成成本忽略返工；社区开始用"集数×段长×抽卡系数×返工率"建模

## 一键式 vs 分步式（结论）
- 一键式适用：口播/营销号/资讯混剪（MoneyPrinterTurbo 70k star=LLM 文案+素材库混剪，非原创画面）
- 付费短剧不能用一键式：强叙事、角色贯穿、付费点（脸/情绪连续性/反转）恰是全自动最不可靠处
- **可行路径="导演式分步 + 环节级自动化"**：自动做初稿（剧本/分镜表/提示词拼接/批量提交/命名归档/粗剪），人工卡三个审点：选脸、关键帧、选片
- Agent 辅助分镜实测返工率 50%→10%（APA 的 CLI/agent 优先由此获益）

## 分镜表真实列结构（收敛）
镜号｜场景｜角色｜景别/机位｜画面描述（谁/在哪/做什么/表情）｜文生图提示词｜图生视频提示词｜台词/旁白｜运镜｜情绪｜预计时长｜生成状态
配套双表方案：提示词库表（名称/类型=主体·风格·构图·光影/内容/效果图）+ 生产表（逐镜一行引用提示词积木、公式拼接、AI 字段直连生成回写）——"改一处全剧同步"
→ APA 验证：shot list 结构与社区收敛一致；差异化机会=抽卡管理（版本/成功率/成本）+一致性资产锁定+生成平台结构化导出，而非再造生成模型
